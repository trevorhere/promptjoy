# Luhmann's Zettelkasten - Obsidian Vault

This vault contains a recreation of Niklas Luhmann's famous Zettelkasten (slip box).

## Structure

- **ZK-1/**: Zettelkasten I (1952-1960) - ~23,000 cards
- **ZK-2/**: Zettelkasten II (1961-1997) - ~67,000 cards
- **Bibliography/**: Referenced works
- **00-Index/**: Navigation aids

## Navigation

Each card uses Luhmann's original numbering system (Folgezettel):
- Numbers and letters alternate to create branches
- `1` → `1a` → `1a1` (deepening)
- `1` → `2` → `3` (parallel sequence)
- Commas indicate sub-branches
