FAQs

How does billing work?

You're invoiced via Stripe after work is completed. No upfront payment required. You'll get an itemized invoice showing hours worked and what was delivered.

Is there a minimum commitment?

Nope. Book a call, scope the work, and pay only for what gets done. No retainers, no contracts.

What kind of work do you do?

AI strategy, workflow automation, chatbots, API integrations, prompt engineering, custom tools — anything where AI can save you time or money.

What tools do you work with?

OpenAI, Anthropic (Claude), open-source models, LangChain, n8n, Make, Zapier, custom code — whatever fits your use case best.

How fast can you turn things around?

Depends on the scope. Small automations might be same-day. Larger projects we'll estimate upfront so there are no surprises.

How do we communicate?

Whatever works for you — Slack, email, Notion, or quick calls. Async-first, but happy to hop on a call when needed.
